# La Chori

Tienda virtual de chorizos precocidos, construida con Hono y Node.js.

## Ejecutar

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Incluye

- Catálogo responsive con filtros por categoría.
- Carrito persistido en el navegador.
- Checkout de domicilio con cálculo de envío gratis desde $60.000.
- Endpoint `POST /api/orders` para recibir pedidos.

Las imágenes del catálogo usan URLs de Unsplash y requieren conexión a internet para cargarse.
